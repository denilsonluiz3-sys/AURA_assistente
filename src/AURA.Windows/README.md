# AURA.Windows

Placeholder for the future "Assistente Windows" module (WMI, Registro,
Serviços, PowerShell) described on the Módulos Disponíveis screen. Not
implemented in the Genesis Core MVP - the module card only records the
user's intent to prepare it (see `AURA.Modules.ModuleCatalog` and
`ModulesConfiguration`). Referenced by `AURA.CLI` today only as an empty
project so the dependency graph in `Arquitetura_AURA_Genesis_2.0` already
exists and compiles.
